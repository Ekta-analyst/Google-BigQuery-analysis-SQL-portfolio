## 🚴‍♂️ Project 1: London Bicycle Analysis
This section covers various SQL queries executed to analyze bicycle trip data, track rentals, and query station details.

### 🛠️ Key Tasks & Queries Performed:
* *Trip Route Tracking:* Queried data to find where a bike trip started and ended, along with the respective station details, rental IDs, and bike IDs.
* *Trip Duration Analysis:* Filtered and calculated how many bike trips lasted for 20 minutes or longer.
* *Station Lookup:* Retrieved specific station names based on station IDs (e.g., finding the station name for ID 111).
* *Comprehensive Record Retrieval:* Extracted complete rental details including rental IDs, station IDs, station names, and bike IDs.
* *Bike Fleet Information:* Queried the specific bike model associated with given bike IDs.
